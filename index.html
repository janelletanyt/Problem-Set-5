My answer to Q1

Q1

Where does my agent sit on our two-by-two map, and what does that mean for the person in the loop?

(a) My quadrant

AI alone, with checks (bottom left)

(b) The two questions

Work with a right answer. Each day has a clear test of whether the job was done right: exactly one email arrives at 8:00 AM SGT, and every story in it is a tech story from a verified source. My runs show this. Every run in my Zap history follows the same three steps: the schedule fires, Code by Zapier builds the digest, and Email by Zapier sends one message. Over 4 runs from 17 October 2026 to 20 October 2026, I could check each digest against those rules and say whether it passed. The one time it failed (an unverified source, see the log below), the failure was clear-cut, which is what a right-answer task looks like.

Work that either of them can do alone. I could read the news sites myself and write the same digest by hand, so a person can do this job alone. The agent also does it alone. There's no step inside the Zap where it waits for me. It collects, builds and sends the digest from start to finish, and I only see the finished email.

(c) The person in the loop

  • Where I stay at the gate: after the work is done, not inside it. My check is the email in my inbox at 8:00 AM SGT, which works as the agent's daily report, plus the Zap history as its log.
  • What I check: that only one digest arrived that day, that every story links back to a source on my verified list, and that the stories are current tech news. When something fails, I fix the code or the source list, not the email.
  • What the agent may do alone: run on its schedule, choose and summarise the highlights, format the digest and send it to my own Gmail. It may not send more than one digest a day or use sources that aren't verified.
  • What would move it: If the digest went to other people, such as a team or clients, I would want to approve it before it went out. If "highlights" came to mean my personal taste rather than verified news, there would be no single right answer. Together, those changes would move it to Agents run it, a person judges. If I only wanted options and picked the stories myself each morning, it would move to A person decides, AI alongside.

(d) My group's view

I agree with where my group placed its tasks in class, and I would answer both of the map's questions the same way the group did. My agent lands in the same quadrant as our group's News briefing, for the same reason: summarising the day's news from good sources is well-defined work AI can do alone, with a person checking against the original sources. The only edge case is the word "personal" in my agent's job. If personal meant taste, the right-answer question could tip the other way. My verified-source rule keeps it a right-answer task, so I'd keep it where the group would put it.

5

Reflection

Where it fitted: The agent fitted a well-defined, repeatable job (one digest a day from verified sources), so it could run alone and my only role was to read the result.

Where it failed: It failed when a story from an unverified source got into the digest, which showed me that "verified sources only" was a rule I had written on the agent card but hadn't fully built into the code.

What I would change: I would add an automatic source check before the email step and include a list of the sources each digest used, so my 8:00 AM check takes seconds and errors are caught before they reach my inbox.
